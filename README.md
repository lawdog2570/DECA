# DECA Assistant (server)

The advisor's assistant for the chapter. It runs on Railway. Slack talks to it, and the advisor uses its web page.

Files:
- `main.py`: the whole server
- `railway.json`: tells Railway how to start it and check it
- `requirements.txt`: no extra packages needed

Nothing secret goes in this repo. Keys and passwords go in Railway's Variables tab.

Stage 1 of 4 is done: health check, status page, admin page and privacy page.
